# GPUI notes

Verified limits of the pinned GPUI (ADR 0009: `zed-industries/zed` at the `rev` in the root `Cargo.toml`). Read these before you design around GPUI.
Paths are in `~/.cargo/git/checkouts/zed-*/<short rev>/crates/`. Check each fact again when the `rev` changes.

| Fact | Source | What we do |
|---|---|---|
| No text or quad transform. `paint_glyph` sets `transformation: TransformationMatrix::unit()` on each sprite. `PaintQuad` has no transform field. | `gpui/src/window.rs`: `paint_glyph` (line 5318, unit matrix at 5379 and 5389), `struct PaintQuad` (line 8413) | Focus zoom paints the glyphs at the zoomed size and moves the quads (`crates/app/src/editor/focus_zoom.rs`). |
| No OS reduced-motion value. The `Platform` trait gives only `window_appearance` (light or dark). `App::reduce_motion` is a flag that the app sets; the OS does not set it. | `gpui/src/platform.rs`: `trait Platform` (line 394), `window_appearance` (line 457); `gpui/src/app.rs`: `reduce_motion` (line 1436) | Reduced motion is a setting, off by default (`crates/core/src/settings.rs`). |
| A variable font has no bold on Linux. For Adwaita Sans, `resolve_font` with weight Bold gives the same font as weight Normal. | `crates/app/tests/fonts.rs`: `in_a_text_font_with_no_bold_face_bold_text_paints_twice_and_a_heading_does_not` | Synthetic bold paints each bold glyph twice (`crates/app/src/editor/synthetic_bold.rs`). A heading gets the accent color, not synthetic bold. |
| The test context does not draw after `run_until_parked`. It only runs the executor. The test window keeps the `on_request_frame` callback and calls it only from `simulate_scheduled_frame` or `simulate_frame_request`, so `request_animation_frame` does not draw. | `gpui/src/app/test_context.rs`: `VisualTestContext::run_until_parked` (line 909); `gpui/src/platform/test/window.rs`: `simulate_scheduled_frame` (line 159), `on_request_frame` (line 580) | Call `window.refresh()` before `run_until_parked` to paint a frame (`crates/app/tests/focus_zoom.rs`, `wait`). |
| `#[gpui::test]` gives a test app with no text system. `TestPlatform::new` uses `NoopTextSystem`: no font names, one font id for all fonts, fixed metrics. | `gpui/src/platform/test/platform.rs`: `TestPlatform::new` (line 133, `NoopTextSystem` at 137); `gpui_macros/src/test.rs`: `TestAppContext::build` (line 164) | App tests run through `system_text::run` (`crates/app/tests/system_text/mod.rs`). It builds each test app with `TestAppContext::build_with_text_system` and the system text system. |
| Window icon only on X11. `WindowOptions` has `app_id` and `icon` (X11 only). `set_app_id` is a no-op on macOS. | `gpui/src/platform.rs`: `struct WindowOptions` (line 2698), `app_id` (line 2766), `icon` (line 2776); `gpui_macos/src/window.rs`: `set_app_id` (line 1923) | Linux: app id `hamish` matches `hamish.desktop`, and the desktop shell takes the icon from it. macOS: the icon comes from `Hamish.app` (`packaging/macos/`). |
| A key goes first to the key bindings of the focus path. A bound key runs its action; when the action stops propagation, no key-down listener sees it. An unbound key goes to the key-down listeners (capture, then bubble). A key no listener stops goes to the text input. A pending multi-key sequence flushes after 1 s. | `gpui/src/window.rs`: `dispatch_key_event` (line 6647), `PENDING_INPUT_TIMEOUT` (line 1447), `finish_dispatch_key_event` (line 6867), `dispatch_key_down_up_event` (line 6910) | Vim mode reads unbound keys in `vim_key_down` and stops the keys it uses (`crates/app/src/editor/vim.rs`, ADR 0008). |
| `Window::dispatch_action` defers: the action runs after the current event handler ends, not at once. `App::open_with_system` hands the path to the platform opener and returns no error. The test platform has no opener: its `open_with_system` is `unimplemented!()`. | `gpui/src/window.rs`: `dispatch_action` (line 2921, `cx.defer`); `gpui/src/app.rs`: `open_with_system` (line 2216); `gpui/src/platform/test/platform.rs`: `open_with_system` (line 838) | A map action runs after the keys of the same key press. Edit hamishrc has no app test; the file creation has a unit test (`crates/app/src/hamishrc.rs`). |
